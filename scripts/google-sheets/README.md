# 居場所マップ × Google Sheets × microCMS

スプレッドシートで居場所を編集し、確認後に microCMS `location` へ反映する運用です。

## ファイル

| ファイル | 用途 |
|----------|------|
| `location-sync.gs` | Apps Script 本体（Code.gs に貼る） |
| `はじめての方へ.md` | メンバー向け手順（シート内タブにも同内容） |

## 役割分担

| だれ | できること |
|------|------------|
| メンバー | 白いセルの編集、タグ編集、「変更あり」チェック |
| 管理者 | 黄色い列（A〜D）、取り込み／反映、選択肢、設定 |

黄色い列（`microCMS_ID` / `確認済` / `反映ステータス` / `最終反映日時`）と「選択肢」タブは **シート保護** でメンバーが触れないようにできます。  
`変更あり`（E列・青）は編集者用のチェックです。

## 初回セットアップ（管理者）

1. スプレッドシート → **拡張機能 → Apps Script**  
2. `location-sync.gs` を **Code.gs** に貼って保存  
3. シートを再読み込み → メニュー **居場所マップ**  
4. **管理者メニュー → 設定を開く**  
   - ドメイン / APIキー（反映は POST+PATCH）  
   - **管理者メール**（自分と、確認済を触る人）  
5. **管理者メニュー → シートを整える（保護も含む）**  
6. **microCMSから取り込む**

メンバーをシートに招待するときは「編集者」でOKです（黄色い列は保護で書けません）。

## メンバーの日常

→ シートの **「はじめての方へ」** タブ、または [`はじめての方へ.md`](./はじめての方へ.md)

要約:

1. 「居場所」で白いセルを直す  
2. タグは「この行のタグを編集」  
3. 「変更あり」にチェック（自動で入ることもあり）  
4. 管理者に一声かける  

## 管理者の日常

1. 「変更あり」がオンの行を確認  
2. **確認済** にチェック  
3. **管理者メニュー → 確認済をmicroCMSへ反映**  
4. （任意）本番再ビルド / Deploy Hook  

## タブ

| タブ | 役割 |
|------|------|
| `はじめての方へ` | メンバー向け手順（保護・改変防止） |
| `居場所` | 1行＝1居場所 |
| `選択肢` | タグ候補（管理者のみ） |
| `記入ルール` | 管理者向け短いメモ |

## 注意

- 選択肢に語を足したら **microCMS のセレクトにも同じ語を追加**  
- 連続反映は約 0.35 秒間隔  
- 保護を外したい／かけ直す → **列の保護をかけ直す**  
- CMS 更新後の本番は Deploy Hook が無いと自動では変わりません  

## 本番の自動デプロイ（任意）

1. Cloudflare Pages → Deploy Hook  
2. microCMS Webhook（Cloudflare Pages）に URL を登録  
3. 対象 API は必要なものだけに絞る
